# 🍄 Mushroom Detect AI

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)
[![Flask](https://img.shields.io/badge/Framework-Flask-lightgrey.svg)](https://flask.palletsprojects.com/)
[![Transformers](https://img.shields.io/badge/Model-Vision%20Transformer-orange.svg)](https://huggingface.co/docs/transformers/model_doc/vit)

Интеллектуальная система распознавания грибов на базе нейронных сетей (Vision Transformer). Помогает определить вид гриба по фотографии и узнать информацию о его съедобности.

---

## 🎯 Цель проекта
Предоставление удобного инструмента для грибников и любителей природы, позволяющего быстро идентифицировать грибы и снизить риски, связанные с ядовитыми видами. 

> [!WARNING]
> Результаты работы нейронной сети носят ознакомительный характер. Никогда не употребляйте в пищу грибы, в которых вы не уверены на 100%!

---

## ✨ Основные возможности
- **Распознавание более 100 видов грибов**.
- **Информация о съедобности**: классификация на съедобные, условно-съедобные, несъедобные и ядовитые.
- **Интуитивный веб-интерфейс**: простая загрузка фото прямо из браузера.
- **Быстрая работа**: использование легковесной модели ViT (Vision Transformer).

## 🚀 Порядок запуска

### 1. Подготовка окружения
Убедитесь, что у вас установлен Python 3.8 или выше. Рекомендуется использовать виртуальное окружение:

```bash
# Создание виртуального окружения
python -m venv venv

# Активация (Windows)
venv\Scripts\activate

# Активация (Linux/macOS)
source venv/bin/activate
```

### 2. Установка зависимостей
Установите все необходимые библиотеки одной командой:

```bash
pip install -r requirements.txt
```

### 3. Запуск приложения
Запустите Flask-сервер:

```bash
python main.py
```

После запуска приложение будет доступно по адресу: **http://localhost:5000**

## 🛠 Технологический стек
- **Backend:** Python, Flask
- **Machine Learning:** PyTorch, Hugging Face Transformers
- **Model:** ViT (Vision Transformer)
- **Frontend:** HTML5, CSS3 (Vanilla)

---

## 📂 Структура проекта
- `main.py` — основной файл приложения и логика обработки изображений.
- `app_config.py` — настройки приложения (пути, пороги уверенности).
- `normalization.py` — база данных названий и статусов грибов.
- `templates/` — HTML шаблоны интерфейса.
- `static/` — статические файлы и папка для загруженных изображений.
- `model/` — веса и конфигурация нейросети.
